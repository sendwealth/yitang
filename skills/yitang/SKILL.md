# 一堂方法论总索引

一堂方法论的核心是**相信并追求客观因果规律**:模糊的认知→随机的结果,顶级的认知→顶级的结果。本技能是路由索引——先判断当前问题属于哪一类,再加载对应方法论。

## 快速路由表

| 你遇到的问题 | 加载的技能 | 核心口诀 |
|---|---|---|
| 不知何事值得用 AI 做 / AI 落地不知从哪下手 | `yitang-scene-star-model` | 场景优先,不拿锤子找钉子 |
| 人机协作结果不好,不知道卡在哪 | `yitang-dual-triangle` | 结果不好不怪 AI 不怪人,是双三角不够强 |
| 决策/复盘/分析缺乏科学姿势 | `yitang-y-model` | 圣人畏因,凡人畏果 |
| 增长乏力,不知道该先做什么 | `yitang-business-formula` | 先切分(+),再拆转化(×) |
| 某个指标怎么打都打不动 | `yitang-cd-loop` | 业务公式找战场,转化率打节点 |
| 想积累 AI 时代的数据资产 | `yitang-ai-data` | 先存再处理,过程数据比结果值钱 |
| 重复向 AI 解释同一件事 | `yitang-skill-encapsulation` | 封装不是把提示词写长,是把判断讲清 |
| 想要一个长期陪伴的角色型 AI | `yitang-partner-encapsulation` | 先定角色(TCPR),双三角准备,只固化验证过的 |
| 输入太慢、上下文给不足 | `yitang-voice-prompting` | 把AI当人,把人当AI |
| 成长停滞,不知处于什么阶段 | `yitang-ai-10x-flywheel` | 卡点根源是阶段与飞轮错配 |

## 使用姿势

1. **先诊断,后开方**:任何问题先问"这属于哪个象限/哪个阶段/哪个三角缺了",不直接跳到工具和技巧。
2. **假设驱动**:给每个行动配一个可验证的假设,用最低成本验证,相信真实世界的反馈。
3. **一次加载一个方法论**:按路由表加载具体技能,按其步骤执行,不要泛泛而谈。

## 方法论之间的关系

- **Y模型**是最底层的工作姿势(因果规律),**双三角**是 AI 时代的竞争力模型,飞轮是双三角的动态形成过程。
- **场景STAR**回答"做什么",**业务公式/C×D**回答"业务怎么拆",**ADAPTED 6+1**回答"数据怎么攒"。
- **Skill/Partner 封装**是复利期的主要动作;**口喷**是贯穿所有阶段的第一基本功。
