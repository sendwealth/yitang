# ADAPTED 6+1:AI 数据全生命周期

> 数据是 AI 三大驱动力(算法/算力/数据)中普通人唯一能抓在手里的核心竞争力,也是唯一不能短期速成的。**用确定性的旧尺子,量不出概率性的新世界。**

## 三个范式巨变

1. **出口变了**:"查字典"→"给教材"——数据的用途变成给 AI 当教材,评估标准完全变了。
2. **形式变了**:"结果表单"→"过程错题"——过程数据(修改痕迹/踩坑记录/错误案例)比最终结果更有价值。
3. **成本变了**:"重金组队"→"AI 飞轮"——AI 大幅降低数据全链条门槛。

## 六步 + 治理

```
A 预判 Anticipate → D 识别 Define → A 收集 Acquire → P 处理 Process → T 使用 Transform → E 反馈 Evaluate
                                                          (+ D 治理 Discipline 贯穿全程)
```

**A 预判——三层价值假设**(以终为始,假设驱动):

| 层 | 比喻 | 时间尺度 |
|---|---|---|
| 微观(上下文) | 教材/说明书 | 即刻可用,最高频 |
| 中观(工作流) | 燃料/助推器 | 1-3 年 |
| 宏观(资产) | 护城河 | 5-10 年,对手无法积累 |

**D 识别——界定事实、语义、优先级**,再按 8 类盘点:事实、语义、过程、反馈、反例、风格、结构、多模态。核心是找"暗数据"——现在不重视、未来大概率会后悔的数据来源。

**A 收集——湖仓思维**:很多高价值数据本来是金子,因为看不懂被当石头扔了。**先存再处理**:先保留原始,再加工结构;湖可以是任何形式(Obsidian、飞书、云盘、截图收藏)。

**P 处理——3 级 8 种**:L1 粗加工(转写/OCR/清洗)→ L2 精加工(结构化/切片/计算)→ L3 注灵魂(标注/萃取)。**Golden Dataset(黄金评测集)是衡量 AI 输出好坏最重要的数据。**

**T 使用**:从简单到复杂——上下文投喂 → Prompt 模板 → Datapack → Skill → Workflow → RAG → 微调。

**E 反馈**:评估效果,回流数据(用 Golden Dataset 评估每次输出好坏,记录输入/修改/采用用于回流)。

**D 治理**:数据规范、合规边界、权限分层、生命周期管理,贯穿全流程。

## 能力段位

L1 缺意识 → L2 盲目囤积 → L3 会处理缺反馈 → L4 建系统不闭环 → L5 有飞轮缺长期 → L6 强壁垒持续领先。

## 操作步骤

1. 为当前 AI 项目写下三层价值假设(这批数据微观/中观/宏观各值什么)。
2. 盘点 8 类数据中自己已有哪些、哪些"暗数据"正在流失。
3. 建湖(先存原始),再定 L1→L3 的加工计划。
4. 优先建 Golden Dataset:收集一批成对的好输出/坏输出样本(数量视场景而定;这是本技能的操作化建议,原方法论未定具体数量)。
5. 设计回流:每次使用的结果如何回到数据(记录输入/修改/采用)。

心法:**相信飞轮**。技能几天上手,审美几周训练,数据只能几周入门、几个月见效、几年形成核心竞争力。
