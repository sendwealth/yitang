# 一堂Y模型(科学理念)

> 模糊的认知→随机的结果;顶级的认知→顶级的结果。**圣人畏因,凡人畏果。**

X 型选手凭感觉、依赖工具/专家、不积累认知;Y 型选手:明确评价维度→建立因果模型→借理论工具→提假设做验证→持续迭代建模。

## 模型四步

1. **核心**:科学只保留一个内核——相信并追求客观因果规律(由此才有可证伪、可复现)。
2. **进步**:认知升级的两个来源——**理论**(抽象过的规律模型)+ **事实**(业务现场的现实)。学习别人的或自己测试的。
3. **姿势**(三大精神最小集):知行合一(认知和实践同步升级)、实事求是(敬畏客观事实,相信自己是普通人)、解放思想(善用新工具解决新问题)。
4. **能力**(四大工具):定性定量、科学类比、假设驱动、提炼建模。

## 三大追求(实操要点)

**知行合一**:"知道"和"能用"是两件事。入门标志是形成对一个复杂事情的基本的、朴素的、框架性认知(框架=基本因果关系,像树干承载叶子)。连一个 1.0 的模型都没有,就没法被讨论、复用、迭代。追问模板:"决定这个结果最重要的 3 个要素是什么?"

**相信理论**:你解决过的问题极大概率早有人抽象成方法论;最大难度在理解边界和科学类比,不是照抄(copy 同行抄了壳子没抄到规律是最常见的坑)。没有现成规律就自己萃取:**SOP/流程 → 原则/方法论 → 底层逻辑/本质要素**(体系建模的完整五层为:经验层→常识层→方法论层→本质层→科学素养层)。修炼工具(建模五件套):深度复盘(事后萃取单个案例)< 深度思考(无案例时的推演)< 模型武器库(积累可复用框架)< 辩证讨论(对抗检验模型)< 爆炸式研究(无现成规律时大量收集案例、分类、定性定量总结规律)。

**相信事实**:绝大多数答案在最佳实践里。定量阶梯:模糊大块时间<具体小时<小时×产能;No Hire/Hire/Strong Hire<分维度打分;<严格财务定量——**定量有成本,重要决策才上高维定量**。假设实验:把主观判断变成客观假设,最低成本验证。理论与事实矛盾时,实践是检验真理的唯一标准。

**三派自查**:几乎每个人都从 Y 模型的一叉起步——纯经验派(缺理论,天花板低、迁移弱)、纯理论派(过度抽象、无法证伪)、纯测试派(重复造轮子)。先诊断自己/用户偏哪派,再尽早补齐缺的那一叉。

## 操作步骤(分析一个问题/方案时)

1. **明确问题与评价维度**:先回答"怎么算好"(没有评价维度的分析是空谈)。
2. **写下当前因果模型**:A→B 的假设链,标注哪些是理论、哪些是事实。
3. **找参照**:这个领域已有的最佳理论/最佳实践是什么?边界在哪?
4. **提假设**:从模型中提出 1-3 个可验证的关键假设,选最低成本验证方式。
5. **定性+定量**:用事实和数据检验,不以偏概全。
6. **迭代模型**:复盘后更新因果模型版本,而不是只记结论。

## 红蓝卡自查(挑最常见的几对)

泛泛而谈↔明确问题 / 主观臆测↔实事求是 / 知行分裂↔知行合一 / 不信规律↔相信规律 / 错误类比↔科学类比 / 以偏概全↔定性定量 / 运气驱动↔假设驱动。发现自己或对话出现红卡苗头,立即停下纠正。
