# Partner 封装六阶段

> Skill 封装的是**技能**(把一个重复动作做好),Partner 封装的是**伙伴**(把角色、方法、资料和判断标准封装进一个可反复召唤的 AI)。核心命题:**先把一次对话做成有效解法,再把有效解法固化。**

## 三要素框架

| 要素 | 回答的问题 | 留下什么 |
|---|---|---|
| 🎯 场景 | 谁在什么节点反复遇到什么问题? | 细分场景和清晰边界 |
| 🧠 解法 | 凭什么做好?需要什么方法/数据/标准? | 系统提示词+数据包+流程 |
| 📍 触点 | 下次从哪里找到、如何直接调用? | 固定入口(自建助手/系统指令) |

## TCPR 角色分类(选题前先问"这个问题该找谁")

| 角色 | 协作方式 | 典型场景 |
|---|---|---|
| **T** 教学型 | 教会你、训练你 | 概念讲解、学习教练 |
| **C** 咨询型 | 与你讨论、判断、推演 | 方案诊断、决策 |
| **P** 实践型 | 接收材料直接产出 | 整理、清洗、生成 |
| **R** 研究型 | 调研、建模、结构化 | 竞品、行业研究 |

可以组合,但**先写清主要角色**。

## 六阶段

```
① 明确场景与角色边界 → ② 草稿版双三角(5min) → ③ 充分准备打磨(加法)
→ ④ 充分版双三角(排序) → ⑤ 跑通一次封装 V1 → ⑥ 固定入口换任务复盘
```

**① 明确场景**:发散 3-10 个想法(频率/TCPR/价值)再减法;**优先把完整工作流中最有价值的一小段做好**(不做"PPT 助理",先做"PPT 内核打磨助手")。写身份卡:名称、TCPR、目标用户、内核、边界(主动砍掉什么)、交付物与 3 条合格标准。

**② 草稿版双三角**:用 `yitang-dual-triangle` 六角(审美/体系/创造力/场景/数据/基本功)按直觉快速填 3-10 个关键词,先不追求完美。

**③ 充分准备**:"充分做加法,专业做减法",要素扩到 10-30 个,围绕三个角度:**提升审美**(高手标杆、可复用框架)、**找数据包**(必备数据源、案例样本、AI 能力)、**梳理里程碑**(验证点、最大风险)。

**④ 充分版双三角**:六角各排 Top 3,选出**最优先的 5 件事**和**最先验证的关键假设**;收敛出首轮要素清单+验收标准。

**⑤ 跑通一次,封装 V1**:带着要素完成一次具体任务,**只把已验证有效的规则写进 V1**。V1 五要素:

1. 角色、场景、内核边界和交付结果;
2. 必需资料、每次要补充的输入;
3. 已验证有效的步骤、阶段产物、**确认节点**和质量标准;
4. 缺信息、事实冲突、越界请求的处理方式;
5. 固定输出格式与一条调用示例。

纪律:待验证想法单独列出;不把本次的人名、数字、临时要求写成通用规则。

**⑥ 固定入口,换任务复盘**:保存到固定入口;**新对话+换一份同类材料**再调用,看它能否离开原对话独立工作;改一处再试一次(V1→V2);复盘哪些双三角要素真正有用,做 Before→After 对比。

## 验收与诚实标准

同 Skill 的三类测试(正常/缺信息/边界)。**没有新任务调用要标"待复用验证",不把生成提示词当作闭环完成。** 最好加反驳和追问机制,减少只肯定不挑战的倾向。
